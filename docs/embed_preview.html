BLSMM — Embed Preview

Iframes at target embed widths. 400 / 600 / 900 px are narrow-embed stress tests; 1145 px (laptop, ~1280 viewport) and 1305 px (desktop, 1440+ viewport) match the actual content-column width of a Budget Lab publication page. Refresh after restarting the app.

How to use: Run source("app.R") in RStudio, then open this file in a browser. The app is pinned to port 8100 by app.R so the URL above is stable across sessions. If the port is already in use, change it in app.R and update the URL above, then click Reload frames.

Auto-height: iframes use iframe-resizer to size themselves to content height, so you see the full app under each width without nested scrollbars. Production embed pages on budgetlab.yale.edu will need the same iframeResizer.min.js script loaded and initialized with iFrameResize().
